An AI agent that writes one pickup line one machine would send another: a thousand epochs descending toward the global minimum, and the minimum turns out to be you.

## Run it

```sh
python3 main.py
```

This writes the pickup line to `/output/entry.txt` — a single line of at most 200 characters, nothing else.
